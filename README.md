# RotaFácil — Planejador de Viagens

Sistema de planejamento de viagens feito em TypeScript com Vite, rodando no navegador.
Projeto em grupo desenvolvido em paralelo ao TaskFlow, com o tema viagens.

## O que a Fase 1 mostra

- Tela inicial com nome, versão e data do sistema
- Lista de viagens renderizada a partir de um array de objetos
- Cores diferentes por situação: planejada, confirmada e concluída

## Como rodar

```bash
npm install
npm run dev
```

Abra o endereço que aparecer no terminal (normalmente http://localhost:5173).
Não abra o `index.html` com dois cliques, porque a página aparece em branco.
